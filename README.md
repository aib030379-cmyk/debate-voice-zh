# 辩论skill · debate-voice-zh

**说人话，有争议，有深度。** 一个用辩论视角写中文稿、改中文稿的 Claude 技能（Skill）。

AI 写的东西读着累，通常不是因为错，而是因为没有立场、没有对手、没有具体的人。辩手正好相反：每句话都在回应一个对手，每个论点都落在一个具体的人身上，最后一句要让人记住。这个技能把辩手的思路变成一套写稿和改稿流程。

## 它会做什么

- **写新稿**：先问你的观点，把话题改写成能站队的辩题，抢一个题眼，替反方立好最强的论点再回应，用一个具体的人讲出来，最后一句收在能截图的金句上。
- **改稿 / 去 AI 味**：按顺序检查立场、对手、具体的人，删掉铺垫、升华、套话和假细节，同时保住原稿的数字、否定词和条件。
- **只要标题或开头**：给 5–10 个有争议感的版本。

交稿时会附上"本篇用了哪些手法"，方便你边用边学。改稿前后的对比见 [examples/before-after.md](examples/before-after.md)。

## 你可以这样说

- "帮我把这篇改得像人写的，去掉 AI 味"
- "用辩论的思路写一篇：年轻人该不该裸辞"
- "这篇太平了，写得有争议一点"
- "给这个话题想 10 个开头"

## 安装

**Claude Code**：把整个 `debate-voice-zh` 文件夹放进 `~/.claude/skills/`。

```bash
git clone https://github.com/aib030379-cmyk/debate-voice-zh.git ~/.claude/skills/debate-voice-zh
```

**Claude 网页版 / 桌面版**：把 `debate-voice-zh` 文件夹压缩成 zip，在 设置 → Capabilities → Skills 里上传。

## 底线

争议来自观点，不来自攻击。这个技能会故意用一些辩论里常见的修辞手法（比如偷换定义、假两难），但只用在观点上，不编数据、不编别人说过的话，不点名攻击普通人，医疗、法律、理财话题不写暴论。
