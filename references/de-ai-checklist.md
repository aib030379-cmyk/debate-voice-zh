# 去 AI 味：症状、改法、自检

## AI 味的常见症状

| 症状 | 长什么样 | 怎么改 |
|---|---|---|
| 没有立场 | "这个问题见仁见智""各有利弊" | 选一边站，写清你站哪边、为什么 |
| 没有对手 | 通篇自说自话，没回应任何反对意见 | 写出反方最强的一个理由，再回应它 |
| 没有具体的人 | "很多人""我们""用户" | 换成一个有名字、有场景的人，最好是你自己 |
| 开头铺垫 | "在当今快速发展的时代""随着 AI 的普及" | 删掉，第一句直接给结论或冲突 |
| 结尾升华 | "让我们一起……""未来可期""值得每个人深思" | 删掉，最后一句停在最有力的那句话上 |
| 格式表演 | 正文里一堆小标题、加粗、列表 | 改回自然段，只在真正需要步骤时用列表 |
| 套话 | "值得注意的是""不难发现""总而言之""赋能""抓手" | 删掉，或者换成你平时说话会用的词 |
| 万能句 | 放到任何文章里都成立的话 | 删掉，换成只属于这篇的细节 |
| 假细节 | "凌晨三点的咖啡""泛黄的笔记本" | 删掉，只留真发生过的细节 |
| 三段对称 | 每个论点都"首先、其次、最后"，每段一样长 | 打乱节奏，重要的写长，次要的一句带过 |
| 过度礼貌 | "希望对你有帮助""欢迎交流" | 删掉，用一个具体的问题收尾 |

## 改稿顺序

一遍只改一件事，按这个顺序：

1. **立场**：读完能不能一句话说出作者站哪边？不能就先补立场。
2. **对手**：有没有回应一个真实的反对意见？
3. **具体的人**：有没有一个具体的人、一件事、一个画面？
4. **删表演**：删铺垫、删升华、删套话、删万能句、删假细节。
5. **中文**：读出来顺不顺？一句是不是只说一件事？同一个东西是不是始终用同一个词？
6. **事实**：数字、名字、引文逐条核对。查不到出处的，删掉或改成"我的感觉是"。
7. **结尾**：最后一句能不能单独截图？有没有给读者一个站队的问题？

## 保住信息

改稿最容易出的事，是把意思改歪了。改完逐条对一遍：

- 数字有没有变？
- 否定词（不、没、别、无）有没有丢或多？
- 条件（如果、只有、除非）有没有被删？
- 专有名词、人名、产品名有没有写错？
- 原稿里真实的经历和细节有没有被删掉？

## 交稿前自检

- [ ] 能一句话说出这篇的立场
- [ ] 回应了一个真实的反对意见
- [ ] 有一个具体的人或画面
- [ ] 开头两句就亮出观点或冲突
- [ ] 正文是自然段，没有多余的标题、加粗、列表
- [ ] 没有套话、万能句、假细节
- [ ] 故意用的谬误只用在观点上
- [ ] 数字和引文都核对过
- [ ] 最后一句能单独截图，结尾有一个问题
