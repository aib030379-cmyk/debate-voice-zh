# 辩论写法速查

下面的例子都是为说明手法写的示范句，换成你自己的话题和经历再用。

## 写稿前的五个问题

1. 我抢的是题目里哪个字？
2. 我换的是谁的视角？
3. 我讲的是哪一个具体的人？最好是我自己。
4. 读者最可能用什么比喻反驳我？我能不能先把它接过来？
5. 最后一句能不能单独截图？

## 一、抢题眼六法（开头和标题最常用）

定义赢了，题就赢了一半。

| 方法 | 做法 | 示范 |
|---|---|---|
| 抠一个字 | 只盯题目里一个副词、动词、量词，重新解释 | "AI 会取代你"——问题不在"取代"，在"你"：你每天做的事，有多少是只有你能做的？ |
| 查字典 / 拆字 | 用字源、字形、谐音给词换个意思 | "忙"字是心加亡。忙到没空想事情，就是这个字的本义。 |
| 换视角 | 换一个题目里没写的当事人 | 都在问"该不该让孩子早点用 AI"，没人问过：被替孩子写完的作业，老师还批不批得出东西？ |
| 缩题 / 扩题 | 把讨论范围划小或划大 | 先把极端情况划出去："我们不聊天才，只聊每天要交差的普通人。" |
| 二难拆题 | 拆成两种情况，两头都通向你的结论 | "这个工具要是好用，你不用就亏了；要是不好用，你得先用过才知道。反正都得试。" |
| 换题型 | 宣布"这其实是另一道题" | "你以为这是一道效率题，其实是一道信任题。" |

## 二、反驳七招（中段、回应反对意见时用）

1. **收编对方的比喻**：对方说"AI 是实习生"，你说"对，所以问题是你会不会带实习生"。最常用、最有效。
2. **点破对方的防线**：对方只举轻的例子，就说"你只挑了最好办的情况"，然后上一个重的。
3. **顺推到荒谬**：顺着对方的逻辑多走一步，走到明显不成立的地方。
4. **抓对方的高频词**：对方反复说"效率"，就问"效率是谁的效率？"
5. **揭穿前提矛盾**：把对方的两种说法摆在一起，让它们自己打架。
6. **一句话拆掉温和例子**：对方挑了最体面的例子，你换一个最常见、最不体面的。
7. **点破套路本身**："写到最后，总会有人告诉你'其实这是一种成长'。"把常见套路说出来，本身就是笑点。

## 三、可以故意用的谬误

只用在观点上，不用在事实上；读者要能看出这是观点。观点稿一篇最多用 1–2 个。

| 手法 | 一句话用法 |
|---|---|
| 偷换定义 | "所谓 XX，其实就是……"，后面全按你的定义走 |
| 假两难 | "要么……要么……，反正都……" |
| 滑坡（当笑点） | 推到荒诞才好笑；推到"看似合理"的极端就是贩卖焦虑，别用 |
| 以个案代全体 | 一个具体的人的故事，胜过十个数据 |
| 类比替换 | "这就像……"，后面接一个人人经历过的场景 |
| 虚假等同 | "说白了，A 和 B 是一回事" |
| 最小对立词 | 造一对只差一个字的词：撑过去 / 撑下去，有意义 / 有意思，对你好 / 为你好 |
| 拆字 / 文字游戏 | 抓住一个口头禅，深挖"它真正的意思" |
| 诉诸自然 | "人本来就……，所以……" |
| 幸存者偏差 | 自己用时，预备被人点破；点破别人时很好用 |
| 诉诸情感 | 把最痛的一句话放在故事最后 |
| 双重标准反问 | "凭什么 A 可以，B 就不行？" |
| 故意露破绽 | 开头先承认"这是个歪理"，读者反而放下防备 |
| 稻草人 / 病理化对方 | 慎用。只能对观点，不能对具体的人；评论区最容易被抓 |

## 四、情绪从哪来（按力度排序）

1. 说话人自己的真实处境：病、伤、失败、当天的动摇。
2. 亲近的人的一个具体细节：一种气味、一句话、一个动作。
3. 大家都认得出的经典：诗词、歌词、电影台词。
4. 讲道理——最弱。

生活里的小故事常常赢过宏大的理论。

## 五、金句句式

| 句式 | 示范 |
|---|---|
| 你以为 A，其实 B | 你以为你在省时间，其实你在省思考。 |
| 不是 A，而是 B | 让人累的不是工作，是假装在工作。 |
| A 只是……B 才是…… | 写出来的只是草稿，删掉的才是风格。 |
| 重新定义 | 所谓专业，就是知道哪一步不能交给别人。 |
| 本质句 | 拖延的本质不是懒，是怕。 |
| 一字之差 | 别让 AI 替你想，让它陪你想。 |
| 谐音造词 | 以前内卷，现在"睡卷"。 |
| 反转俗语 | 工欲善其事，先别急着利其器。 |
| 续写俗语 | 笨鸟不怕先飞，怕的是被人发现是笨鸟。 |
| 对仗 | 灰度认知，黑白决策。 |
| 排比三连 | 同一个句式连说三次，第三次最狠。 |
| 反常识断言 | 最好的效率工具，是把一半的事删掉。 |
| 把时间拉长 | "八十岁的你回头看""这辈子"——时间一拉长，小事就变重。 |
| 镜头转回读者 | 你呢？你站哪边？ |

## 六、一篇稿子的节奏

先让人笑（放下防备），再讲一个具体的人（产生代入），最后一句把情绪推到顶（让人想转发）。结尾抛一个二选一，评论区自然有人站队。
